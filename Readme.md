# Disease Prediction from Medical Data using AI & ML

An interactive web application developed to automate disease diagnosis based on patient-inputted symptoms. Built using Python, Machine Learning, and Streamlit.

##  Features
- **Automated Prediction:** Uses a trained **Decision Tree Classifier** to analyze symptoms and predict potential diseases.
- **User-Friendly UI:** Developed with **Streamlit** for an interactive, web-based user experience.
- **Data-Driven Accuracy:** Pre-processed and trained on standard medical datasets.

##  Tech Stack & Libraries
- **Language:** Python
- **Framework:** Streamlit (for UI development)
- **ML Library:** Scikit-learn (Decision Tree Classifier)
- **Data Handling:** Pandas, NumPy
- **Model Persistence:** Joblib

## Methodology
1. **Data Collection & Pre-processing:** Cleaned missing values and handled data normalization.
2. **Feature Selection:** Selected relevant symptoms (e.g., skin rash, vomiting, cough, high fever, headache).
3. **Model Training:** Implemented a Decision Tree algorithm for efficient classification.
4. **Deployment:** Hosted locally using Streamlit.
